### 퀴즈
다음 중 옳지 않은 것을 모두 고르시오.
1. HTTP 메세지는 결코 업스트림으로 흐르지 않는다.
2. 프로토콜 버전이 HTTP/1.1 이라는 것은 오직 HTTP/1.1 만 이해 함을 나타낸다.
3. TCP는 포트 번호를 통해서 여러 개의 커넥션을 유지한다.
4. 패킷이 성공적으로 전달되는 각 시점에 송신자는 추가로 2개의 패킷을 더 전송할 수 있는 권한을 얻는 것을 TCP 느린 시작이라고 한다.
5. 프락시는 GET 요청을 바로 서버로 통과시키고, POST 요청은 웹 캐시와 같은 다른 HTTP 애플리케이션으로 전송한다. 
6. HTTP/1.0의 keep-alive 커넥션과 달리 HTTP/1.1의 지속 커넥션은 기본적으로 활성화되어 있다.

- 정답 : 2,5
  - 2 :  프로토콜 버전이 HTTP/1.1 이라는 것은 HTTP/1.1 버전 까지 이해함을 나타낸다.
  - 5 : 프락시는 POST 요청을 바로 서버로 통과시키지만, GET 요청은 웹 캐시와 같은 다른 HTTP 애플리케이션으로 전송한다. 
    - 5번 추가 설명 :
      - GET 요청
        → 보통 “읽기/조회”라서 캐시해도 안전한 경우가 많음
        → 그래서 프락시는 웹 캐시를 먼저 보고, 있으면 캐시에서 바로 응답함

        POST 요청
        → “작성/수정/주문”처럼 서버 상태를 바꾸는 요청
        → 캐시를 쓰면 위험해서 프락시는 그대로 원 서버로 바로 보내버림
        -> POST는 서버 상태를 바꾸는 중요한 작업이 많아서, 캐시를 끼우면 중복 처리·옛날 데이터·개인정보 노출 위험이 생기기 때문에 보통 “캐시 안 쓰고 서버 직행”으로 다룬다.

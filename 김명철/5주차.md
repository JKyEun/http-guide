1. 루트 집합(Root Set)과 구글 서치콘솔 색인 추가

2. 체크섬(Checksum)이란?
데이터 무결성을 검증하기 위한 고정 길이의 값입니다.
원본 데이터: "Hello World"
     ↓ 해시 함수 적용
체크섬: 0a4d55a8d778e5022fab701977c5d840bbc486d0 (SHA-1)
HTTP에서의 활용:
httpHTTP/1.1 200 OK
Content-MD5: Q2hlY2sgSW50ZWdyaXR5IQ==
ETag: "abc123def456"
용도설명파일 다운로드 검증다운받은 파일이 손상되지 않았는지 확인캐시 유효성ETag 헤더로 리소스 변경 여부 판단중복 콘텐츠 탐지크롤링 시 같은 내용의 페이지 식별데이터 전송 오류 검출TCP/IP 레벨에서도 사용

5. Playwright 크롤러의 User-Agent
Playwright는 실제 브라우저를 사용하므로, 해당 브라우저의 User-Agent가 전송됩니다.
javascriptconst { chromium } = require('playwright');

(async () => {
    const browser = await chromium.launch();
    const page = await browser.newPage();
    
    // 기본 User-Agent 확인
    const ua = await page.evaluate(() => navigator.userAgent);
    console.log(ua);
    
    // 출력 예시:
    // Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 
    // (KHTML, like Gecko) HeadlessChrome/120.0.0.0 Safari/537.36
})();
주의: HeadlessChrome이 포함되어 봇 탐지에 걸릴 수 있습니다.
커스텀 User-Agent 설정:
javascriptconst browser = await chromium.launch();
const context = await browser.newContext({
    userAgent: 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36'
});
const page = await context.newPage();
```

## 6. 풀 텍스트 색인(Full-Text Index)

**문서 전체 내용을 검색 가능하게 만드는 인덱싱 기법**입니다.

**일반 DB 인덱스 vs 풀텍스트 인덱스:**
```
[일반 인덱스]
SELECT * FROM articles WHERE title = 'HTTP 완벽 가이드'
→ 정확히 일치하는 것만 찾음

[풀텍스트 인덱스]
SELECT * FROM articles WHERE MATCH(content) AGAINST('HTTP 프로토콜')
→ "HTTP", "프로토콜" 단어가 포함된 모든 문서 검색
```

**역색인(Inverted Index) 구조:**
```
원본 문서들:
  Doc1: "HTTP는 웹의 기초 프로토콜이다"
  Doc2: "TCP 위에서 HTTP가 동작한다"
  Doc3: "웹 브라우저는 HTTP를 사용한다"

역색인 테이블:
┌──────────┬─────────────────┐
│ 단어     │ 문서 목록       │
├──────────┼─────────────────┤
│ HTTP     │ Doc1, Doc2, Doc3│
│ 웹       │ Doc1, Doc3      │
│ TCP      │ Doc2            │
│ 프로토콜 │ Doc1            │
│ 브라우저 │ Doc3            │
└──────────┴─────────────────┘

"HTTP 웹" 검색 → Doc1, Doc3 반환 (둘 다 포함)
```

**검색엔진의 풀텍스트 색인 파이프라인:**
```
웹 페이지 → 크롤링 → HTML 파싱 → 텍스트 추출
                         ↓
              토큰화 (단어 분리)
                         ↓
              정규화 (소문자 변환, 어간 추출)
                         ↓
              불용어 제거 (the, a, 은, 는...)
                         ↓
              역색인 구축 → 검색 가능!
